## 安装方式

### 方式一：从 Releases 下载

1. 访问 [Releases](../../releases) 页面
2. 下载最新 `.d115p` 文件
3. 在 DIAN115 插件中心上传安装

### 方式二：添加自定义仓库

在 DIAN115 插件中心添加以下仓库地址：

```
https://github.com/[username]/dian115-plugins
```

服务端会自动解析为：
```
https://raw.githubusercontent.com/[username]/dian115-plugins/main/plugin-market/index.json
```
